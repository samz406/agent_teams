# Agent Teams 页面体验改版

## 数据口径与边界

“今日完成”按本机日历日期统计：协作任务当前状态为 DONE 且状态更新时间在今日，岗位工作单为 SUCCEEDED 且 completedAt 在今日。现有协作任务没有独立 completedAt 字段，因此不将该数字解释为不可变的历史完成事件数。首页运行统计覆盖协作任务和工作单；讨论成果可见，但讨论轮次不计入任务完成数。

计划展示时间转换为本机时间，同时保留计划配置的时区。交付物跳转携带文档 ID，避免打开同任务内其他文档。审批批准只影响选中文档，阶段推进仍检查任务验收、阻塞问题与人工确认要求。用量金额保留 CLI 报告/既有版本费率估算口径，不等同于订阅实际扣费；未报告与未计价不冒充零消耗。

自定义 Agent 的预检只验证命令已配置，命令是否能启动由运行时验证；普通目录只允许关闭写入后继续，写入执行使用既有 Git 工作树机制。工作台数据来自快照，不新建数据库实体、不修改审批门槛。

## 验证结果

- `npm test`：64 项通过，其中 6 项新预检/日期测试、7 项新组件交互测试。覆盖历史日期排除、有效/失效绑定、缺失环境、只读普通目录、自定义命令、准确文档跳转、审批失败不推进、审批已保存但推进失败提示、退回意见必填、员工→工作单导航、执行记录切换、抽屉 Escape、未知用量、三步创建载荷与导航折叠持久化。
- `npm run typecheck`、`npm run build`：通过。
- 组件交互使用 happy-dom 和隔离 DesktopApi 测试替身，不运行真实收费 Agent；原有运行、数据库和状态机测试保留。
- `npm run smoke:ui`：提供正式 renderer + preload + 隔离 IPC 的 Electron 窗口检查脚本，覆盖 1440/1024/760 三种宽度与关键交互。当前执行环境的 Electron 无法进入 ready 状态，脚本超时，因此**尚未完成真实窗口截图和视觉验收**；不能将组件测试当作布局验收。

## 本地复核

运行 `npm ci` 后执行 `npm run dev` 启动桌面应用。`npm test` 会将 SQLite 本地模块重建为 Node ABI，`dev` 会按现有流程恢复 Electron ABI。可运行 `UI_SCREENSHOT_DIR=/绝对路径 npm run smoke:ui` 保留检查截图；该脚本不调用真实模型。视觉复核重点：760px 窗口中的团队开关、审批按钮与输入框；1440px 下的团队摘要和执行详情抽屉；较长中文标题及方案正文的换行。手动使用真实项目创建一次任务，检查 Runtime 权限、Token 上报和审批推进；此项需要本机已配置可用 CLI。
